## Proposed taxonomy (pending human approval, nothing generated yet)

Tier 1 = a foundation document per category. Tier 2 = deep-dives beneath each. Tier 3 = reference tables. Tier 4 = meta.

### Game Mechanics

- **Foundation:** core survival loop (hunger, thirst, health, radiation, temperature, comfort)
- Depth: combat and damage model, movement/vehicles, wildlife and NPCs, monuments and loot tables, events (heli, cargo ship, bradley), electricity and logic

### Items & Crafting

- **Foundation:** resources, crafting and the blueprint/research system
- Depth: weapons and ammo, tools, clothing and armour, food and farming, workbench tiers, component and scrap economy

### Building & Raiding

- **Foundation:** building system and tool cupboard/upkeep
- Depth: base design, deployables and turrets, raiding costs (explosives, soft-siding), defence and offline protection

### Server Administration

- **Foundation:** dedicated server setup (SteamCMD, ports, launch parameters, `server.cfg`)
- Depth: convars, wipes and map generation, RCON/ServerTap, permissions, performance, Facepunch server rules and anti-cheat (EAC)

### Modding & Plugins

- **Foundation:** Oxide/uMod and Carbon frameworks
- Depth: plugin installation, permissions and config, writing plugins (hooks API), popular plugin categories, framework differences

### Game Updates & Meta

- **Foundation:** update cadence (monthly force wipe, first Thursday) and how to read devblogs
- Depth: major update timeline, wipe schedules, game modes (vanilla/softcore/modded), platform and licence notes, community terminology

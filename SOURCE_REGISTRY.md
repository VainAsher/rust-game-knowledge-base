# Source Registry

Ranked source authority for this KB. Workers cite from the top down and prefer the highest-ranked source that covers a claim. Registry rows are added by the orchestrator from worker returns.

## Source-priority order

1. **Facepunch official** — rust.facepunch.com blog/devblogs and changelogs, Facepunch's server documentation, and the Steam store page (Primary)
2. **In-game data and official tooling** — values read from the game or official server files, the Rust Wiki pages that cite them (Primary or Practitioner, labelled)
3. **Framework documentation** — uMod/Oxide docs, Carbon docs (Primary for modding claims)
4. **Community-maintained databases** — e.g. RustLabs, Rust Wiki (Practitioner)
5. **Community discussion** — Facepunch forums, Reddit, Discord, Steam Community, YouTube (Practitioner, lowest weight; never sole source for a High confidence claim)

## Source classes

| Class | Meaning |
|-------|---------|
| Primary | Facepunch or framework authors, first-party |
| Practitioner | Community databases, wiki, forum threads |
| Further Reading | Non-cited background |

# Rust (Facepunch) Game Knowledge Base

An evidence-based, source-cited reference for the PC/Steam survival game **Rust**, for players and server admins. Unofficial and not affiliated with Facepunch Studios.

Build locally: `pip install pyyaml` then `python scripts/validate.py`, `python scripts/audit_genre.py --strict`, `python scripts/build_graph.py`, `python scripts/build_site.py`.
